🌟 Chrome WebXR 설정 가이드

⚠️ 중요: macOS Safari는 WebXR을 지원하지 않습니다. Chrome을 사용해주세요!

1️⃣ Chrome에서 WebXR 활성화

Chrome 주소창에 다음 입력:

chrome://flags

검색할 항목들:

  • WebXR Device API → Enabled
  • WebXR Incubations → Enabled
  • OpenXR support → Enabled

설정 후 Chrome 재시작 필수!

2️⃣ Chrome에서 테스트

WebXR 진단 테스트 메인 AR 앱

3️⃣ 모바일에서 테스트 (진짜 AR)

Android Chrome:

http://172.30.1.49:8080/webxr-test.html

iPhone Safari:

http://172.30.1.49:8080/webxr-test.html
모바일과 PC가 같은 Wi-Fi에 연결되어 있어야 합니다.

4️⃣ iPhone Safari 설정 (iOS 17.4+)

설정 경로:

  1. 설정 → Safari
  2. 고급 → 실험적 기능
  3. "WebXR Device API" 활성화
  4. "WebXR Gamepad Support" 활성화

5️⃣ Android Chrome 설정

Chrome flags 설정:

chrome://flags
  • WebXR Device API → Enabled
  • WebXR AR Module → Enabled

🎯 예상 결과

PC Chrome: WebXR API 지원, AR 세션 지원 안됨 (카메라 없음)

Android Chrome: 모든 테스트 통과 예상

iPhone Safari: iOS 17.4+에서 대부분 통과 예상

🚀 테스트 순서

  1. Chrome flags 설정 후 재시작
  2. PC Chrome에서 WebXR 진단 테스트
  3. 모바일에서 실제 AR 테스트
  4. 문제 발생 시 로그 확인
