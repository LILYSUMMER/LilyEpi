처음 한 번만 설정

이 페이지는 서버 없이 브라우저에서 바로 GA4 Data API를 부릅니다. 사장님 Google 계정으로 로그인하면 보이고, 아무것도 저장되지 않습니다(ID 두 개만 이 브라우저에 기억).

  1. GA4 관리 → 속성 설정 → 속성 ID(숫자 9자리). 측정 ID(G-DXQEGVBYP8)가 아닙니다.
  2. Google Cloud Console → 사용자 인증 정보 → OAuth 클라이언트 ID(웹 애플리케이션) 만들기. 승인된 JavaScript 원본에 https://epispace.kr 추가. 같은 프로젝트에서 Google Analytics Data API 사용 설정.
  3. GA4 관리 → 맞춤 정의 → 맞춤 측정기준(이벤트 범위)으로 ms s n kind method phase 등록. 등록 전 데이터는 소급되지 않습니다.
