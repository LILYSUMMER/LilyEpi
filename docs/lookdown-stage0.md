# LOOK DOWN · 0단계 「비춤」 — 만든 것과 남은 것

2026-10-12 기준. 브리프(「LOOK DOWN AR 제작 브리프」)의 0단계 범위만 만들었습니다. 기능은 더 보태지 않았습니다.

## 어디서 열리나

- 주소: `https://epispace.kr/lookdown/` (GitHub Pages, 이 레포의 `lookdown/` 폴더)
- 회사 이름·로고는 화면에 없습니다. `noindex`라 검색에 안 잡힙니다. 홈페이지·사이트맵에서도 링크하지 않았습니다.
- 전용 도메인으로 옮기려면 이 폴더를 그대로 두고 CNAME만 바꾸면 됩니다(열린 결정 5).

## 체험 흐름 (링크 → 20초)

| 시각 | 화면 | 코드 |
| --- | --- | --- |
| 0초 | 글 한 줄 「비 오는 밤엔, 바닥을 보세요.」+ 버튼 하나. 설명 화면 없음 | `index.html` |
| 버튼 | 한 번의 터치로 방향 센서(아이폰)·카메라·소리 권한을 한꺼번에 | `run()` |
| ~1초 | 카메라 켜짐. 힌트 「바닥을 비춰 보세요」 | |
| 바닥을 0.5초 비추면 | 그 자리에 웅덩이가 고임 (1.6초) | `placePuddle()` |
| +0.9초 | 물속에서 금빛이 먼저 비침 | `S.light` |
| +2.4초 | 머리가 올라오고, 올라온 뒤 귀가 쫑긋 | `S.up`, `S.ears` |
| +0.8초 | 한마디(자막 한 줄, 기기 언어) + 웅얼거림 + 반짝임 펄스 1회 + 물결 | `caption()`, `mumble()` |
| 6초 뒤 | 자막 사라짐. Yuni는 떠 있고, 수면을 두드리면 귀가 옆으로 누웠다 돌아옴(놀람). 연달아 두드리면 짧은 웅얼거림 | `S.startle` |
| 10초 더 보면 | 「비 오는 날 또 와요.」 귀를 뒤로 젖히고(안심) 3초에 걸쳐 가라앉음. 두드리면 그만큼 더 머묾 | `leaving` |
| 가라앉은 뒤 | 웅덩이와 물결만 남고 「다시 비추기」 | `gone` |

카메라 화면이 어두울수록 Yuni가 또렷하고 밝으면 희미합니다(0.6초마다 평균 밝기를 잽니다). 카메라가 없으면 밤으로 칩니다.

처음 열고 Yuni까지 걸리는 시간은 바닥을 바로 비추면 약 3초, 한마디까지 약 6초입니다. 측정 이벤트(GA4): `lookdown_open`, `lookdown_started`, `lookdown_pool`, `lookdown_yuni_seen`(ms), `lookdown_line`(ms), `lookdown_done`, `lookdown_bye`, `lookdown_dwell`(초), `lookdown_no_camera`, `lookdown_tap_water`.

## 세계관 규칙이 코드에 어떻게 들어갔나

- 수면 위 = 카메라 실사, 수면 아래 = 비침. 웅덩이는 스텐실 포털이고 포털 안쪽만 물속이 보입니다.
- Yuni는 물 밖으로 못 나갑니다. 수면(y=0) 기준으로 클리핑해서 머리와 상반신만 위로, 아랫몸은 포털 안에서만 보입니다. 끌어내는 조작은 없습니다. 카메라가 웅덩이를 벗어나면 Yuni도 화면 밖입니다.
- 외형: 불투명한 따뜻한 빛의 둥근 몸(#F2B45A 발광) + 작은 고양이 귀 + 검은 점 눈 두 개. 입·코·윤곽선 없음. 깜빡임 없음. 머리 지름 11cm(브리프 제안 8~12cm).
- 감정은 귀 각도로만. 쉴 땐 살짝 벌어지고, 떠오른 뒤 쫑긋, 두드리면 옆으로(놀람), 돌아갈 땐 뒤로(안심).
- 반짝임: 밝기 펄스 1회, 0.75초 올라가 1.27배, 0.75초 내려옴. 기본 발광을 낮게 잡아 과노출을 막았습니다.
- 움직임: 물결 퍼지듯 천천히. 떠오를 땐 물속 빛 → 머리 → 귀 순서. 동심원 물결 동반.
- 말: 두 문장 이하, 설명·재촉·광고 문구 없음. 접수·도장·영수증 같은 사무 화면 없음.
- 제주·이름 뜻·분실물 사연은 0단계에 없습니다(공개 범위).

## 기술 답 (열린 결정 2·4)

**플랫폼은 외부 서비스 없이 자체 WebAR입니다.** three.js 0.160(이미 레포에 있음) + 기기 방향 센서. 서버 없음, 앱 없음, 가입 없음.

- 포털 마스크와 물결 셰이더는 iOS Safari에서 도는 WebGL 스텐실·셰이더만 씁니다. 레포의 `rain-portal-ar.html`이 같은 방식으로 이미 아이폰에서 돌았습니다. **10/14 「데모 1개로 확인」 항목은 이 페이지를 아이폰에서 여는 것으로 끝납니다.**
- **바닥 평면 인식은 iOS Safari 웹에 없습니다**(WebXR AR 미지원). 그래서 브리프 제약 1대로 "바닥을 비추면 고인다"를 기본 경로로 만들었습니다. 자이로로 휴대폰이 바닥 쪽을 향하는지 보고, 눈높이 1.4m로 바닥 위 자리를 셈해 거기에 고입니다. 걸어서 이동하는 건 못 따라가지만, 제자리에서 휴대폰을 돌리는 동안은 자리를 지킵니다. 웅덩이 밖 바닥을 탭하면 그 자리로 옮겨 고입니다.
- 한국 시청자(웅덩이 없음)도 같은 경로입니다. 위치 제한 없음.
- 센서가 없으면(PC) 화면을 끌어서 봅니다. 카메라가 없으면(인스타그램 앱 안 브라우저 등) 밤 거리 그림 위에 띄우고 아래에 작은 안내 한 줄을 둡니다. 어느 경우에도 Yuni는 나옵니다.
- 자막은 기기 언어로 한 줄(한·영·중). `?lang=en` 으로 강제할 수 있습니다.

### 소리 파일 넣기

로컬 `~/Claude/` 의 자산을 이 이름으로 넣으면 됩니다. 없으면 빗소리는 노이즈로 대신하고 웅얼거림은 건너뜁니다.

- `lookdown/audio/rain.mp3` — 빗소리 루프(`rain_15s.wav`를 1.5초 크로스페이드로 이어 붙여 mp3로)
- `lookdown/audio/mumble_1.mp3`, `mumble_2.mp3`, `mumble_3.mp3` — 웅얼거림 변주(`mumble_1.mp3`, `mumble_line1_b_low.wav`, `mumble_line2_b_low.wav`)
